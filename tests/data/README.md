# WP09 conformance and hostile-input corpus

Every redistributed byte below is locally authored from a cited standards rule.
No W3C test-suite file is copied. `PROVENANCE.toml` pins the applicable
Recommendation/date, license terms, transformation statement, local SHA-256,
and review owner. `tools.corpus.manifest` fails closed if a corpus file is
missing, unregistered, mutable, or hash-mismatched.

The compact corpus is deliberately reviewable. Generative and mutation suites
derive bounded variants at test time; only minimized regressions are retained.
Large ontologies remain external hash-pinned manifests and are never downloaded
by ordinary tests.
