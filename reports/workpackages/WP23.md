# WP23 — component-scoped anonymous canonicalization v2

Status: implementation checkpoint complete; final native-artifact, large-corpus,
performance, and release gates pending
Prepared: 2026-08-02
Release claim: not made

## Outcome

Anonymous graphs are now partitioned into connected components before
canonical refinement. Document-wide labels and arcs remain charged to
`max_terms`, while `max_canonical_work` is enforced independently for each
component. Complete canonical component graph bytes, a sorted
multiplicity-preserving manifest, component-class occurrence ordinals, and
model-schema-2 identity domains prevent disconnected isomorphic anonymous
individuals from collapsing.

Python and retained-native implementations use the same scheme. Independent
reference vectors exercise source-label, root-order, component-order, and hash
seed permutations, including repeated isomorphic components and true duplicate
roots. One oversized connected component still fails closed through WP19's
typed `ResourceLimitError` contract.

The coordinated public version ledger is implemented as package `0.2.0`, API
`(0, 2)`, model schema `2`, wire `(1, 2)`, adapter protocol `1`, and encoded
structural schema `2`. WP22's frozen
`LoadOptions.allow_partial_rdf_mapping=False` API and native V2 option ledger
are incorporated. Model and encoded schema 1 remain frozen and are not
reinterpreted.

This is an implementation checkpoint, not incident closure or a release
claim. The final extension has not been rebuilt and tested across the complete
forced-native matrix, the required one-pass corpora and comparison benchmarks
have not all run, and the release gates remain blocked.

## Public anonymous telemetry

The native report exposes the following exact non-negative integer values
under the `native_anonymous_` prefix in `LoadReport.timings`:

- component count, total labels, and total arcs;
- largest component labels, arcs, and roots;
- maximum root-interval span and maximum open root intervals;
- total setup, refinement, candidate-order, and canonical work;
- largest component work and maximum refinement rounds;
- total permutations examined; and
- anonymous-phase accounted bytes.

Native accumulation uses checked integer sums. Python rejects negative,
non-exact, or greater-than-`2**53` values before the existing float-compatible
public timing conversion. Syntax parse, result encode, arena construction, and
freeze phase timings remain available separately.

`native_anonymous_accounted_bytes` is the exact non-negative increase in the
operation's monotonic `Session` memory-budget charge from entry into the common
schema-2 anonymous scoping helper through completed raw/effective canonical
rows and occurrence-digest tables. The wrapper's ontology-key construction is
charged to the same operation-wide budget before that checkpoint and is
deliberately excluded from this phase-specific value. The counter records
conservative allocation work; it is not live allocation, allocator high-water
usage, or process RSS. Same-machine peak RSS therefore remains part of the
external final-corpus evidence.
