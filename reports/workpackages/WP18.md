## Outcome

WP18 now has an executable, strict evidence schema that derives
`core_release_eligible` and `workspace_optimization_complete` independently.
The checked-in checkpoint names all ten required core gates and all five exact
consumer revisions; unknown, missing, duplicate, or malformed rows fail before
a decision is produced. A pass requires evidence, while every fail or not-run
row requires a reason. The current result is intentionally false for both
decisions: zero complete core gates and zero complete workspace consumers.

This checkpoint also closes two narrower integration risks without promoting a
capability. Mapped composite views now preserve mapped column ownership and
derive anonymous-document lineage directly from validated encoded columns. The
guarded retained Functional load publishes its native owner without rebuilding
a complete Python structural model, and the direct/decoded/mmap/empty-overlay/
two-member-composite matrix proves independent-decoder parity, retained owners,
zero scalar base paging, zero eager structural objects, and zero referenced
buffer copies. A fresh installed native wheel now also publishes the complete
single-document common-contract structural/fingerprint ledger from one
Rust-owned compact summary, so the timed adapter no longer walks a second
encoded DAG. Complete formats, import closure, security, artifacts,
comparators, and consumer performance remain open.

The core private-extension handshake is also fail-closed at ABI 3. ABI 2 lacks
the explicit retained-RDF/XML `allow_swrl` argument and ABI 1 also predates the
final retained-Functional call surface. Both stale artifacts are rejected
during metadata validation before self-test or any retained-parser call,
closing the source-tree failure mode where an old PyO3 signature was selected
and raised only after dispatch. This changes no public schema, capability, or
release decision.

The semantic-reference parser is now isolated from backend dispatch at commit
`ce8cbba`. Public loading still selects the requested backend through a neutral
orchestration layer, while direct `PythonParser` use remains Python-only and
cannot probe a native artifact. A detached full-suite run at `c8f18e7` passed
1,139 tests and 3,546 subtests with seven explicit skips, providing a clean-tree
integration check without changing either release decision.
