# WP01 handoff report

## Scope completed

WP01 implements the complete syntax-neutral OWL 2 structural value layer and
the explicitly namespaced SWRL structural extension. The checkpoint is the
`main` commit containing this report.

The permanent schema contains 76 constructor tags: six typed entity classes
share the single `ENTITY` structural branch, while the SWRL branches retain
extension tags but are public only from `pyowl_core.extensions.swrl`. The root
package and `pyowl_core.model` expose the non-SWRL structural surface.

Implemented behavior includes:

- frozen, slotted values for primitives, typed entities, annotations, property
  expressions, all data/class expressions, all OWL 2 axioms, and SWRL values;
- deterministic `CanonicalSet`, ordered structural tuples, local type/arity/
  cardinality validation, annotation retention, and canonical flattening;
- model-schema-tagged self-describing bytes, minimal unsigned varints,
  canonical decode rejection, stable SHA-256 structural digests, and
  hash-seed-independent Python hashing;
- document-scoped anonymous identities, bounded partition refinement and
  symmetric tie enumeration, explicit re-scope provenance, and lexical-token
  provenance outside structural equality;
- exhaustive registry-based visitors/walking/signatures, caller-owned
  interning, and model-scoped `DocumentBuilder` identity creation;
- structural validation plus honest incomplete OWL 2 DL/profile reports and
  the shared object-role hierarchy/simplicity analysis foundation; and
- a generated W3C/SWRL production table and an exact valid fixture inventory
  for every tagged branch.

## Frozen WP01 decisions

Schema-1 canonical fields use explicit component markers for nodes, text,
bytes, nonnegative integers, string-valued enums, unordered sets, ordered
sequences, and optional `None`. Nodes use permanent unsigned-varint tags and
fixed dataclass field order; framed lengths are minimal unsigned varints. A
decoder accepts only bytes that re-encode identically, so alternate markers,
unsorted/duplicate sets, nonminimal varints, and trailing bytes fail.

Typed entities are convenience subclasses with one shared `(EntityKind, IRI)`
canonical constructor/tag. Intersections and unions flatten their own nested
constructor and deduplicate before enforcing minimum arity. Direct nested
`ObjectInverseOf` is rejected by its named-property field; `inverse_property`
collapses an inverse to its named property. Language validation implements the
RFC 5646 structural grammar, including private-use and grandfathered forms,
and canonicalizes accepted tags to lowercase.

`DocumentBuilder` is intentionally model-scoped: it creates stable
programmatic anonymous identity and lexical provenance, but it does not parse,
freeze an ontology document, resolve imports, or own WP02 document state.
Complete OWL 2 DL/profile closure checks remain explicitly `complete=False` so
no incomplete analysis can be reported as conforming.

## Deviations and blockers

No standards deviation was introduced and no expected-failure marker was
added. The table cites primary W3C specifications but copies no external test
artifact, so no external-fixture provenance record is required.

Complete reserved-vocabulary, datatype-definition, property-regularity, key,
anonymous-individual, and EL/QL/RL closure validation requires resolved
documents and remains a WP03/WP09 responsibility. `OntologyID`,
`OntologyDocument`, syntax parsers/writers, source maps, import-cycle tests,
consumer compatibility keys, native parity, and wire/reference-index dispatch
remain with their manifest owners (WP02 onward).

The runtime wheel embeds generated model tags and passed installed imports.
Adding the source `schemas/` ledger to the release sdist manifest remains the
WP12 packaging owner's coordinated release task.

## Handoff

WP02 may rely on:

- every non-SWRL name in `pyowl_core.model.__all__` and the matching curated
  root exports in `tools/audit/public-api-v0.txt`;
- SWRL values only from `pyowl_core.extensions.swrl`;
- the permanent constructor/tag/field contracts in `CONSTRUCTOR_SPECS` and
  `schemas/model-v1.toml`;
- `canonical_bytes`, `decode_canonical`, `structural_digest`, visitors,
  `CanonicalSet`, `OWLFactory`, `DocumentBuilder`, and validation report
  interfaces; and
- `tests/generated/model/fixtures.py` and
  `w3c-production-coverage.json` as the exhaustive downstream dispatch input.

Later work packages must not reinterpret canonical bytes, anonymous scope,
language identity, collection ordering, or entity kinds. Any schema-1 change
requires the model-schema change process; consumer-specific normalization stays
in adapters rather than the shared model.
