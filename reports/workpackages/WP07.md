`WP07-native-foundation.md`:

  unwinding/overflow checks, a developer extension-module link hook, and
  `#![forbid(unsafe_code)]` throughout the crate root;

  metadata, self-test, stable sanitized error codes, owned input/output buffers,
  panic containment, GIL release, atomic cancellation, deadlines, and periodic
  `KeyboardInterrupt` delivery back as the original Python exception;
- a frozen 312-byte configuration frame carrying all 37 `ParseLimits` values
  without narrowing, plus checked native memory, count, offset, length, work,
  arity, depth, IRI, literal, rule, document, and wire budgets;
- a safe private arena and a bounds-first canonical-schema-1 scanner covering
  every one of the 76 core/SWRL constructors, exact field markers and roles,
  canonical collection order/flattening, entity kinds, absolute IRIs, literal
  datatype/language rules, inverse-property ordering, and `HasKey`/SWRL rules;
- a dependency-free streaming SHA-256/CRC32C implementation and complete owned
  PYOCORE v1 validator/round-tripper for the 14 required tables, optional SWRL,
  integrity/version/bounds/reference/semantic ledgers, unknown optional
  sections, ordinary snapshots, overlays, and composites;
- a validated Python adapter and capability-first dispatcher implementing exact
  `PYTHON`, `NATIVE`, and `AUTO` behavior, one warning per process/reason,
  post-fork cache/lock reset, and proactive rejection of PyPy, free-threaded
  CPython, and subinterpreters; and
- forced-native tests for ABI policy, every constructor, goldens, systematic
  truncation/mutation, resigned semantic corruption, limits, owned mutable
  buffers, threads, GIL release, cancellation, deadlines, signals, panic,
  fork, unsupported runtimes, and pure-backend import isolation.

The legal/capability decision is clean-room native code. No Horned-OWL,
`py-horned-owl`, JNI, Java archive, or Java runtime dependency is linked. The
active Rust tree is PyO3 and its build/macro dependencies; licenses are
MIT/Apache-2.0-compatible, with `target-lexicon` carrying the standard
Apache-2.0 LLVM exception and `unicode-ident` also carrying Unicode-3.0 terms.
This avoids advancing the separately gated Horned-OWL LGPL path.

## Deviations and blockers

PyO3's macOS `extension-module` feature deliberately leaves CPython symbols for
dynamic lookup, so an all-feature Rust *test executable* cannot be launched as
a standalone binary on macOS. The gate is therefore split as intended: unit
tests use `--no-default-features --features test-hooks`, while all-feature
build/Clippy and real CPython dylib loading exercise extension mode. This is a
platform link-mode property, not a product failure.

No unsafe block exists, so host Miri cannot add meaningful coverage to this
crate's code beyond the safe-Rust compiler checks, and PyO3's CPython FFI is not
a Miri-hosted runtime. WP07 establishes the sanitizer/fuzz foundation through
panic containment, `forbid(unsafe_code)`, systematic hostile mutation and
truncation corpora, bounded allocation/work tests, and retained typed failure
oracles. Dedicated cross-platform ASan/TSan/libFuzzer CI and minimized corpora
remain the manifest-owned WP09 security gate.

The Cargo build hook is sufficient for a direct developer extension build.
PEP 517 `PYOWL_CORE_BUILD_NATIVE=auto/0/1`, sdist inclusion, wheel tags, and the
release artifact matrix require coordinated edits to `pyproject.toml`,
`setup.py`, `MANIFEST.in`, and release workflows, all explicitly owned by WP12.

No remaining WP07 blocker prevents WP08 from implementing complete native
parser/index capabilities on this ABI and wire foundation.

## Handoff

WP08 may add a capability only after its whole-operation native implementation
passes parity and may use the 37-value configuration ledger, cancellation guard,
safe model scanner/arena, and owned PYOCORE boundary. It must not advertise the
existing parser/snapshot/index stubs: they intentionally return
`NATIVE_CAPABILITY_UNAVAILABLE`, and current `FEATURES` advertises foundation
capabilities only. WP12 should package this exact locked crate without changing
ABI/model/wire version claims or enabling unsupported runtime modes.
