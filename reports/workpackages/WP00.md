# WP00 handoff report

## Scope completed

WP00 establishes the installable, typed `pyowl-core` foundation without
starting WP01's OWL structural model. The checkpoint is the `main` commit that
contains this report.

Implemented public foundation surface:

- package/API/model/wire/adapter version constants fixed at `0.1.0.dev0`,
  `(0, 1)`, `1`, `(1, 0)`, and `1`;
- exact public error hierarchy and warnings from `specs/contracts.md`, with
  validated stable codes and immutable diagnostic round trips;
- `DocumentFormat`, `ImportPolicy`, `BackendPreference`, immutable
  `ParseLimits`, and immutable secure-by-default `LoadOptions`;
- thread-safe cooperative `CancellationToken`/`CancellationSource`; and
- immutable progress events, callback protocol, and bounded thread-safe buffer.

Repository controls include a deterministic permanent tag-ledger generator,
architecture/public-API/metadata/provenance/Java audits, local and pre-commit
commands, contribution/security/deviation/report guidance, and Python 3.10/
3.12 plus hash-seed CI. No model constructor, parser, snapshot, index, wire
codec, native module, or consumer adapter was added.

## Deviations and environment-only gaps

No standards deviation was introduced.

The local macOS host has Java, Clang, and Rust installed, so physical absence
of those executables could not be demonstrated locally. The `pure-package` CI
job performs the build/install in `python:3.10-slim` after asserting that Java,
Javac, Rust, and a C compiler are absent; it keeps the package build and smoke
install offline. The local environment lacked the `build` and `twine` CLIs, so
the equivalent PEP 517 backend/pip paths were exercised; release-grade Twine,
SBOM, signing, platform, and publication checks remain WP12 work.

The provisional `pyowl-core` name is not claimed or published, and project URLs
remain omitted instead of retaining placeholders. Name reservation and real
URLs are release blockers owned by WP12/WP13.
