## Outcome

Malformed RDF axiom and annotation reifications now fail with bounded
structural evidence instead of prose alone. `UnsupportedSyntaxError` exposes
an immutable `reification_evidence` sequence and exact
`reification_issue_count`, `reification_evidence_count`, and
`reification_suppressed_count` values. The first retained diagnostic is also
the primary diagnostic; a zero-retained internal boundary still exposes
reconcilable counts.

The stable reason vocabulary is:

- `MAIN_TRIPLE_ABSENT`;
- `METADATA_INCOMPLETE`;
- `METADATA_AMBIGUOUS`;
- `METADATA_TYPE_INVALID`;
- `NODE_KIND_CONFLICT`;
- `ANNOTATION_CYCLE`; and
- `UNCLAIMED_MAIN_TRIPLE`.

When known, each diagnostic includes the reification subject, annotated
source/property/target, target kind, and whether the main triple is present.
Missing or ambiguous metadata omits unavailable fields rather than inventing
placeholders. Values are sanitized, credential-redacted, individually capped
at 4 KiB, collectively capped at 32 KiB, ordered deterministically, and
limited by `max_diagnostics`.

Python preflight aggregates all malformed reification nodes before raising.
The native mapper emits the same bounded records and counts in a validated
private payload; the public bridge reconstructs ordinary diagnostics and
rejects malformed payloads. No absent main triple is synthesized.
