# WP16 — native streaming parsing and structural mapping

Status: implementation checkpoint; narrow Functional retained-load handoff
implemented, complete native ingestion acceptance open
Prepared: 2026-07-20
Capability claim: none

## Outcome

WP16 now has a fail-closed retained-owner handoff for one deliberately narrow
public load shape: one Functional Syntax document, forced native parsing,
ignored imports, provenance enabled, source maps disabled, OWL 2 DL validation
disabled, no RDF mapping report, and no anonymous-node re-scope difference.
The handoff preserves canonical structural rows and exact origin occurrences in
the typed V2 owner. Its encoded structural view and PYOCORE writer consume the
retained columns without scalar model traversal. The installed-wheel regression
crosses native load, retained publication, direct columns, wire encoding,
decoding, mmap reopening, owner lifetime, and close behavior.

This is a checkpoint, not WP16 acceptance. The current public load first parses
and reconstructs an ordinary Python `OntologyDocument` and
`OntologySnapshot`; `native_ingestion.py` then canonicalizes those Python model
objects again to construct the retained owner. It therefore does not yet feed
the retained arena directly from the native parser and does not satisfy the
work package's proportional-object or no-reconstruction goal. The bridge is
intentionally absent from the ingestion capability ledger, and the encoded
view schema is likewise unadvertised.

## Acceptance state

WP16 acceptance remains open. In particular:

- no public optimized path yet streams parser output directly into the retained
  arena without first building a proportional Python document/snapshot;
- RDF/XML, Turtle, and OWL/XML are not complete native ingestion paths, and the
  full Functional format/option/import matrix has not passed retained
  publication;
- native closure assembly does not yet prove shared-import digest parsing,
  diamonds/cycles, anonymous scopes, partial failure, cancellation, or
  deterministic bounded parallel publication;
- complete diagnostics/source-position, writer, W3C/corpus, hostile, fuzz,
  memory/object, and phase-allocation evidence is absent; and
- no ingestion format or encoded schema may be advertised from this checkpoint.

WP16 can close only after each advertised format completes the installed-wheel
forced-native matrix, unsupported selections fail before consumption, fallback
detection remains active, and parser-to-arena plus retained-closure evidence
demonstrates that no RDFLib graph, proportional Python triple/axiom collection,
or eager complete Python model conversion occurs.
