## Performance outcome

The 20-run tiny baseline, five-run 9,999-axiom large matrix, and five-run pinned
Uberon matrix pass all recorded assertions. On the large source:

- native public parse throughput is 1.12x and native load/freeze throughput is
  1.65x; no 2x parser claim is made;
- native axiom-index build is 2.01x faster (0.361 versus 0.726 seconds), which is
  the documented alternative benefit justifying the optional artifact;
- AUTO remains within 10% on tiny load and routes small work to Python;
- mmap open is 3.7–7.7% of matching full load and allocates 0.70% of full-decode
  traced heap;
- one-axiom overlay and two-base composite peaks are 5,217 and 7,504 bytes,
  against a 16 MiB limit; and
- handoff p95 is below the shared-host 1 ms calibration and all core work
  counters remain zero.

Uberon Python parse/load/mmap medians are 2.143/5.391/0.331 seconds; mmap is
6.1% of load and 0.58% of full-decode traced allocation. Its five repetitions
are informative because the small-corpus release rule asks for 20.

Profiles locate repeated canonical encoding, freeze/fingerprint work,
native-result materialization, and wire validation/materialization. The
existing native index removes a measured duplicate key pass. WP10 deliberately
does not add a global per-node canonical-byte cache: the retained-memory trade
has not been measured across biomedical loads. Safety and determinism checks
remain enabled.

## Limitations and consumer handoff

`reports/performance/limitations.md` records the non-reference shared host,
single-run HPO qualification, strict NCIt/ORDO mapping failures, unavailable
Exact/py-horned comparison, and Python 3.12-only performance calibration.

Consumers should continue passing an existing `OntologyView` directly. The
measured `coerce_snapshot(existing_view)` boundary preserves exact identity and
does no ontology work. Use wire/mmap only for explicit process or persistence
boundaries. The package remains Java-free and the complete pure-Python runtime
remains the fallback on Python 3.10/3.12 and unsupported native platforms.
