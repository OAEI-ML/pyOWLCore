## Stabilization decision and blockers

No model equality, canonical identity, wire meaning, or adapter negotiation was
changed to make the documentation convenient. The frozen candidate remains:

| Domain | Candidate |
|---|---:|
| package | `0.1.0.dev0` |
| API | `(0,1)` |
| model schema | `1` |
| wire | `(1,1)` |
| adapter protocol | `1` |

All five recorded consumers currently constrain core to the 0.1 line (package
requirements `>=0.1,<0.2` or API `(0,1)`). Their recorded commits predate later
workspace work. A 1.0 version therefore requires coordinated range changes and
a new exact-commit matrix; it cannot be inferred from the stable model/wire
numbers.

WP13 acceptance remains open until WP12 has a release-ready signed report, all
master checklist items have linked evidence, project name/URLs are approved,
and release and consumer owners approve the export/version decision. There are
no approved deviations for those blockers.
