# pyowl-core 0.1.0 release-owner override

Date: 2026-07-30

The release owner explicitly authorized production publication of `pyowl-core`
`0.1.0`, directed that all remaining external gates be closed, and accepted
local account-scoped PyPI token upload in place of GitHub Trusted Publishing
and TestPyPI rehearsal.

This decision does not rewrite or relabel historical reports. It is the
accountable release decision for this publication. The release retains the
existing Java-free universal fallback, optional native acceleration,
compatibility range, rollback procedure, and immutable-artifact requirements.
